MT7601U Wi-Fi

This installs a userspace Wi-Fi driver and a menu bar app for the MediaTek MT7601U USB adapter (USB 148f:7601).

  • A background daemon (mt7601ud)
  • The menu bar app “MT7601U Wi-Fi” (connection status, network list, connect)
  • The mt7601u-wifi command

Supports 2.4 GHz networks with WPA2-PSK or no security. Traffic goes through a dedicated network interface (utun); the adapter does not appear in the standard macOS Wi-Fi settings.

This is experimental software. For Intel Macs (x86_64). Plug the adapter into a USB port before using it.
